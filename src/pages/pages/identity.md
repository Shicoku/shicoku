# このページについて

このページでは、Shicoku / 詩哭の表記およびロゴに関するルールを記載しています。  
名前やロゴを引用する際は、必ず本ページの内容を遵守してください。  
なお、交流や日常的な会話においては、この限りではありません。  
オリジナルキャラクター「歌街凪音」のガイドラインは、[こちらのページ](/pages/identity/nakine)にまとめています。

## 名前

名前の表記は以下の通りとします。

- 詩哭
  - 基本的に漢字で記載してください。
  - 必要に応じて平仮名でふりがなを付けても構いません。
- Shicoku
  - 先頭のみ大文字、以降は小文字で記載してください。
  - やむを得ない場合に限り、すべて大文字 / すべて小文字での記載も許容します。
- その他の表記
  - 漢字やアルファベットが使用できない場合に限り、平仮名表記 (しこく) を使用できますが、できるだけ避けてください。

名前を引用する場合は、必ず下記のいずれか一方の XのID または リンクを併記してください。

- [@Sck_Day](https://x.com/Sck_Day)
- [@Shicoku\_](https://x.com/Shicoku_)

読み方は以下の通りとします。

- 読み方は「しこく」です。
- 発音の指定は特に設けません。
- ただし、日本にある地名「四国」と同じイントネーションを公式の読み方とします。

## ロゴ

ロゴの使用は一般には許可していません。使用を希望する場合は、Shicoku / 詩哭までご連絡ください。

- 色
  - 使用できる色は **白（#ffffff）** または **黒（#000000）** のみとします。
  - 明度の調整は必要に応じて行って構いませんが、その他の色での使用は認めていません。
- 改変
  - ロゴそのものへの加工・編集・改変は一切認めていません。
- サイズ
  - 必要に応じてサイズを調整して構いません。
  - 極端に縮小したサイズや、極端に拡大したサイズなど、視認性を損なう使用は避けてください。
- 余白
  - ロゴの周囲には適切な余白を確保してください。
  - 最低 **10px** 以上の余白を推奨します。
